How the codebook grew

Each serendipity codebook version side by side (v1.0). The first version was built from the papers. Each later version adds codes for anomaly themes that recurred in the round before it, and may revise or drop codes; the papers behind each added code are listed with it. Hover a code for its papers. Level 2: worked out from the level-1 codes, story by story
Definition
  • D1 Busch (2024): Agency, surprise and value
  • D2 Dew (2009): Search, chance and prior knowledge
  • D3 Walpole, after Merton and Barber (2004): Accident and sagacity
Rival
  • R1 Pure luck: Surprise and value without agency (Busch 2024, p. 29)
  • R2 Targeted search or a plan: Agency and value without surprise (Busch 2024, p. 29)
Type
  • T1 Mertonian: sought, found unexpectedly: A specific search, answered by the problem already in mind
  • T2 Walpolian: sought one, found another: A specific search that changed the plan
  • T3 Bushian: exploring, met an existing need: No specific search, but a problem already in mind
  • T4 Stephanian: solution first, problem later: No specific search and no problem in mind
Judgment
  • J1 Told as if planned: The story is told as intended, though its details show unplanned turns
  • J2 Working with what's at hand: Built from the founder's own means, with no surprise
