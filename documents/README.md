# documents

Supporting files. Editors and reviewers do not need this folder: what they read is
in `../1_package/`.

| File | What it is |
|---|---|
| `docs/codebook/questions.json` | The research question's sub-questions, read by the program when it writes the round pages |
| `docs/codebook/drafts/prompt_draft2.md` | The instructions that built codebook 1.0 from the papers; codebook 1.0 records point here |
| `docs/technical_v2/process.json` | Every step of Stages 2 and 3: who does it, its files and what it records. The process page and Figures 3 and 4 are drawn from it |
| `docs/technical_v2/figures.py`, `figures_pptx.py`, `views.py` | Draw the technical appendix's figures and the process page |
| `build_submission.py` | Builds this repository from our working files and checks that it holds no interview text or papers |

In our working files this folder is called `harness_v2/`. Paths in the records that
begin with `harness_v2/` refer to this folder.
