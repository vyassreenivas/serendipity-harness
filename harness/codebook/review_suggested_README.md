# Suggested review of the 360-code draft (pilot codebook)

`review_suggested.csv` is a suggestion, not a decision. It was written by
Claude Opus 5.5 in a Claude Code session on 20 October 2026, reading the
draft from run `20261012-124904`. The researchers check every row and save
their own decisions as `review.csv`; only that file is read by `freeze`.

Criteria used:

- **Core** (coders apply it to every interview): a coder can see it in a
  founder's account, it is supported by the papers, and it is central to its
  sub-question. About four per group, 43 in all, because coders handle about
  30 to 40 codes at a time (MacQueen et al. 1998).
- **Definition codes** follow open point 3, option 3A (not yet decided):
  surprise, agency and value give the broad verdict (Busch 2024); a search
  already under way is added for the narrow verdict (Dew 2009).
- **Reject** only clear duplicates or codes in the wrong group; the reason
  names the code it duplicates. Background is what the founder brings;
  condition is the circumstance (Stage 1 rule).
- **Accept, not core**: everything else. These codes stay in the codebook as
  reference, for reviewing misfits and for later rounds.
- No wording was changed. Revisions are for the researchers.

Changed 21 October 2026, at the researchers' request: the type group follows
Yaqub's (2018) typology. Bushian (type-05) and Stephanian (type-06) are added
to the core and all four of his types carry his names (Walpolian, Mertonian,
Bushian, Stephanian). Core codes: 45.
