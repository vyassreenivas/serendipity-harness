How the codebook grew

Each serendipity codebook version side by side (v1.0, v2.0, v3.0, v4.0-draft). The first version was built from the papers. Each later version adds codes for anomaly themes that recurred in the round before it, and may revise or drop codes; the papers behind each added code are listed with it. Hover a code for its papers. Anomaly themes still open, carried forward to the next round: 32.
